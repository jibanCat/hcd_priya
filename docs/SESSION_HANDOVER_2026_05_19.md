## 2. Phase 2 design — the locked decisions

Read the spec for the full design; the headline decisions:

- **τ₀ rescaling = "freeze-core".** The mean-flux dimension is generated by
  rescaling the Lyα optical depth: for each α, **freeze pixels with native
  τ > 1e6** (self-shielded DLA / strong-sub-DLA cores — physically
  UVB-insensitive, per Rahmati+2013 self-shielding), and apply the **uniform
  factor α to every other pixel** (forest, LLS, weak sub-DLA, far damping
  wings). 20 α values, uniform over [0.66, 1.36].
- **Tier-A twin + Tier-C spot-checks.** A uniform-rescale ("Tier A") cache is
  built as a *measured systematic*; 2–3 `fake_spectra` re-extractions at a
  scaled Γ ("Tier C") give ground truth. Smooth Rahmati attenuation ("Tier B′")
  and the freeze-boundary sensitivity sweep are deferred to Phase 3.
- **CDDF / dN/dX are τ₀-invariant.** Absorbers are classified on *native*
  N_HI; cores are frozen, so column densities don't move with α. Therefore
  **Head A takes (params, z) only — no τ₀**; Head B takes (latent, τ₀). This
  resolves the earlier worry that the DLA CDDF moves with τ₀ — physically it
  should not (self-shielded).
- **The emulator replaces Rogers+2018 `DLA4corr`.** The observable contaminated
  P1D is reconstructed as `Σ_c w_c·A_c·P_c` — per-class emulated P1D weighted
  by class fractions from dN/dX, with tight-prior residual amplitudes `A_c` as
  a safety valve. Replacing (not reproducing) the analytic multiplier is the
  whole point of the per-class heads.
- **Architecture (unchanged from 2026-05-05 §4.B):** JAX; shared encoder
  [10→256→128→64] over 9 params + z → 64-d latent; Head A [64→128→33]
  (f_nhi[30] + 3 dN/dX); Head B [65→256→200] ((latent, τ₀) → 4×P1D[50]).
  Single-fidelity (LF) for Phase 2; log-space targets; NaN-safe joint loss.

## 4. The PRIYA `tau_thresh=1e6` correction (important)

The 2026-05-15 `priya-coarse-grid-dive.md` stated PRIYA's production
`tau_thresh=1e6` is "effectively off". **This was wrong** and is now corrected
in that doc's §6. Verified two independent ways this session:

- **Theory:** a line-center Lyα τ of 1e6 corresponds to log N_HI ≈ 19.1–19.6
  (b = 10–30 km/s); a DLA (log N_HI ≥ 20.3) has peak-pixel τ ≈ 5×10⁶–1.5×10⁷.
  `fake_spectra` does not cap τ.
- **Empirical:** across 3 sim/snap pairs (~1.4M absorbers), **100% of DLAs and
  ~56% of sub-DLAs** have a core pixel τ > 1e6.

So PRIYA's `tau_thresh=1e6` genuinely masks the saturated cores of every DLA
and the strongest sub-DLAs — a real DLA-strength cut. This is why the
freeze-core boundary in the spec is set at τ = 1e6.
