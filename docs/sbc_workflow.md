# SBC + Held-Out Validation Workflow

A runbook for running, resuming, and analyzing the inference-validation SBC for the
Phase-C differentiable likelihood. This is the code-repo operational doc; the science
narrative lives in the notes repo (`/home/mfho/hcd_priya_notes`).

All paths are absolute. The forward, mock generation, and NUTS all live in
`hcd_analysis/emulator/closure_legb.py`; the SLURM-array runner is
`scripts/run_prod_sbc_shard.py`.

---

## 1. What the SBC validates — and the two modes

The SBC runs the **actual production likelihood** (`build_legb_ctx` with the N=5 ensemble
forward, deployed cross-class `C_emu`, MF P1D+dN/dX correction, eBOSS metals) over many
mock datasets, fits each with NUTS, and checks that the truth is recovered in a
calibrated way. There are **two modes**, selected by the `leg_a` flag
(`scripts/run_prod_sbc_shard.py:140-142`, `closure_legb.py:run_legb` at `:1962`):

### Mode A — self-draw (`leg_a=True`, the DEFAULT)

- **Truth ~ prior**, then a **matched-C self-draw**: the mock is generated by the SAME
  forward used in the likelihood, so `C_mock ≡ C_like` and **emulator misspecification
  CANCELS by construction** (`run_prod_sbc_shard.py:1-9`, `closure_legb.py:1962-1995`).
- Tests the **inference geometry** — priors, reparametrizations, NUTS sampling, the
  `[θ, τ₀]` correlation handled by `dense_mass=True`.
- **Gate = rank uniformity** (the ECDF simultaneous-band test, Säilynoja+2022) at
  `L_eff ≥ L_FLOOR` (=99), per quantity, A_p and n_s primary
  (`merge_prod_sbc_shards.py:1-19, 99`). The band-sizing floor `L_FLOOR=99` is imported
  from `closure_sbc`; `closure_legb.py:75` defines its own `L_FLOOR=99` for the Leg-B
  smoke's ECDF.
- Truth drawn by `draw_leg_a_leg_truth` (`closure_legb.py:1089`); mock built by
  `make_leg_a_legmock` (`closure_legb.py:1155`); `sim="leg_a_prior"`.

### Mode B — held-out (`leg_a=False`, the HONEST certifier)

- The mock **truth is a HELD-OUT-SIM's MEASURED P1D** (a sim `final_fold0` never saw),
  and the likelihood forward is the **emulator prediction** — so the mock **CONTAINS
  emulator error** (the sim≠emu discrepancy). This is the honest n_s instrument; the
  self-draw cannot see emulator error because it cancels (`run_prod_sbc_shard.py:136-142`,
  `closure_legb.py:1996-2003`).
- Mock truth assembled from the held-out sim's cache rows by `make_truth_from_sim`
  (`closure_legb.py:684`) → leg-binned + cosmic-only noise by `make_legb_mock`
  (`closure_legb.py:941`). The held-out pool is `held_out_sims(d, fold=0)`
  (`closure_legb.py:636`) = **8 sims** for fold 0 (verified). Noise is cosmic-ONLY
  (`ε ~ N(0, C_data)`), NOT added emulator noise.
- **Gate = pull `|mean| ≤ 0.3` AND pull-std `≤ 1.1`** for n_s across the held-out mocks
  (`analyze_sbc_heldout.py:11-13, 120-132`). Rank uniformity is **false-by-construction**
  here (the mock and forward differ), so coverage/bias is the right read, not rank.
- Standing rule: always report **τ₀ amplitude + dτ₀** pulls alongside any cosmo bias
  (`analyze_sbc_heldout.py:11-13`; the `feedback-report-tau0-dtau0-bias` memo).

## 2. How to run it

The runner (`scripts/run_prod_sbc_shard.py`) runs **one mock at a time**, writing
`{out_dir}/mock_{m:04d}.pkl` **atomically** (tmp + `os.replace`) after each mock and
**skipping** at the loop top if that pkl already exists — so an OOM/wall loses ≤1 mock and
a resubmit resumes (`run_prod_sbc_shard.py:11-18, 48-111`). The per-mock RNG is
`fold_in(seed, m)` so a shard subset reproduces exactly the mocks a single full run draws
(`run_legb` docstring `:1950-1952`).

### 2a. Held-out validation (Mode B) — `scripts/batch_sbc_heldout.sh`

```bash
# PILOT: one mock per held-out sim (mock m -> held_out_sims(fold0)[m % 8]).
sbatch --array=0-7 scripts/batch_sbc_heldout.sh

# SCALE-UP: 48 = 6 noise realizations of each of the 8 held-out sims (production n_s cert).
N=48 sbatch --array=0-47 scripts/batch_sbc_heldout.sh
```

- Defaults: `--mem=32g`, `--cpus-per-task=4`, `--time=24:00:00`, account `cavestru1`
  (`batch_sbc_heldout.sh:13-25`).
- Array semantics: `mock m -> held_out_sims(fold0)[m % 8]` (so `--array=0-7` = 1 noise
  realization each; `0-47` = 6 each). `N_MOCKS=${N:-24}`, one mock per shard
  (`batch_sbc_heldout.sh:5, 28-29`).
- The wrapper itself fast-paths a SKIP if `mock_<TID>.pkl` exists
  (`batch_sbc_heldout.sh:43-45`), and the runner skip-cache is the authoritative one.
- It passes `--held-out` (=> `leg_a=False`) and `--no-shard-pkl`
  (`batch_sbc_heldout.sh:48-50`).

**Env overrides** (read by the batch script / runner):

```bash
# subDLA amplitude prior width arm -> its OWN dir (the config-key skip-cache also guards):
SBC_SUBDLA_AMP_SIGMA=0.20 \
  OUTDIR=/scratch/cavestru_root/cavestru1/mfho/prod_sbc_heldout_amp020 \
  N=48 sbatch --array=0-47 scripts/batch_sbc_heldout.sh
```

(`OUTDIR` default `/scratch/cavestru_root/cavestru1/mfho/prod_sbc_heldout`,
`batch_sbc_heldout.sh:30-33`.)

### 2b. Self-draw SBC (Mode A) — `scripts/batch_prod_sbc_pilot.sh`

There is **no dedicated `leg_a=True` batch script under a `_heldout` name** — `leg_a=True`
is the runner DEFAULT, so the standard production-ensemble batch scripts ARE the self-draw
SBC:

```bash
# PILOT (24 mocks, 8 shards x 3):
OUTDIR=/scratch/cavestru_root/cavestru1/mfho/prod_sbc_pilot \
  sbatch --array=0-7 scripts/batch_prod_sbc_pilot.sh
# then aggregate:
python scripts/merge_prod_sbc_shards.py --shard-dir <OUTDIR>
```

- `batch_prod_sbc_pilot.sh:1-23` (`--mem=24g`, `--cpus-per-task=8`).
- The slope-fix / OOM-fix production self-draw runs are `batch_prod_sbc_slfix.sh`
  (N=32, mem=16g) and `batch_prod_sbc_slfix2.sh` (N=48, mem=24g, per-mock checkpoint);
  same runner, no `--held-out`.
- The width-check arm `batch_prod_sbc_*` / `batch_sbc_amp020_widthcheck.sh` exports
  `SBC_SUBDLA_AMP_SIGMA=0.20` and pins `N_MOCKS=48` so `fold_in(seed,m)` aligns mock m
  with the 0.40 baseline run — the correct per-arm SBC construction
  (`batch_sbc_amp020_widthcheck.sh:1-49`).

### 2c. Re-submitting a walled / slow mock

A mock that hit the 24h wall (or a slow hard-posterior straggler) left **no** `mock_*.pkl`,
so just re-submit that array index with a longer `--time` (the skip-cache resumes the rest):

```bash
sbatch --array=37 --time=48:00:00 scripts/batch_sbc_heldout.sh   # only mock 37, longer wall
```

The completed mocks are skipped instantly; only index 37 re-runs.

## 3. Env vars / knobs

| Knob | Where | Effect |
|------|-------|--------|
| `OUTDIR` | env (batch) | output dir for the per-mock pkls. **Must be unique per config** (see the config-key skip-cache gotcha §5). |
| `N` (`N_MOCKS`) | env (batch) | total mocks; held-out maps `m -> sim[m%8]`. `--array` must match. |
| `SBC_SUBDLA_AMP_SIGMA` | env -> runner | subDLA AMPLITUDE prior width override (`σ/μ`). `>0` overrides `inference.HCD_PRIOR_FRAC_SIGMA[1]`; asserted to propagate to `ctx.alpha_hcd_sigma[1]` (no silent no-op) (`run_prod_sbc_shard.py:160-169, 213-216`). Default 0 = production prior. |
| `SBC_CEMU_VARIANT` (or `--cemu-variant`) | env/CLI | which `C_emu` the forward uses: `current` (deployed: emucoh ON @ `[0.0102,0.069]` table, mf_shape OFF), `fixed` (MODE-1 low-k emucoh table + MODE-2 mf_shape ON), `oldc` (== `current` control). Asserted to actually change DESI-leg `C_emu` (`run_prod_sbc_shard.py:143-212`). |
| `--time` / `--mem` / `--array` | sbatch | wall / memory / shard set. Held-out NEEDS `--mem=32g`. |
| `--held-out` | runner | `leg_a=False` (Mode B). Omit for self-draw (Mode A). |
| `--no-mf` / `--no-eboss` | runner | drop the MF correction / eBOSS leg (defaults ON). |
| `--single-member` | runner | use `final_prod_seed0` only — cheap de-risk, NOT the production object. |
| `--no-res-corr-on` / `--res-corr-on` | runner | **placeholder only** — the NORC forward flag is NOT yet wired into `build_legb_ctx`/`data_likelihood`; it just records intent in meta (`run_prod_sbc_shard.py:22-29, 126-131`). |

**Seed / reproducibility.** Default `--seed 20260614` (`run_prod_sbc_shard.py:119`). The
per-mock key is `jax.random.fold_in(seed, m)` (`closure_legb.py:1978, 2001`), so any
subset/scale-up of mock indices is reproducible and disjoint — a SLURM array splitting
`range(n_mocks)` merges to exactly what one full run would draw.

**NUTS config** (`closure_legb._run_nuts_legb` at `:1605`, defaults in
`run_prod_sbc_shard.py:120-123`):

- `n_warmup=250`, `n_samples=600` (≥600 targets `L_eff ≥ 99` after thinning; NUTS
  ESS ≈ 0.18/sample).
- `max_tree_depth=10` (matches the production leg fit).
- `dense_mass=True` (the `[θ, τ₀]` correlation is real physics; `closure_legb.py:1608`).
- `target_accept` retry schedule: starts at 0.9, then **0.95 → 0.99** on any divergence
  (`DIVERGENCE_RETRY_TARGET_ACCEPT`, `closure_legb.py:76, 2006-2017`). A clean mock breaks
  at the first attempt.
- `num_chains=1` per mock; `init_to_median` init (`closure_legb.py:1642, 1631`). The
  multi-chain R-hat/E-BFMI convergence battery is a separate path (`run_legb_convergence`,
  `init_to_sample`).

## 4. Analysis

### 4a. Held-out pull gate — `scripts/analyze_sbc_heldout.py`

```bash
PYTHONPATH=/home/mfho/hcd_priya /home/mfho/.conda/envs/emu-jax/bin/python3 \
  scripts/analyze_sbc_heldout.py \
  /scratch/cavestru_root/cavestru1/mfho/prod_sbc_heldout sbc_heldout
```

Args: `SRC_DIR` (default the held-out OUTDIR) and `OUT_PREFIX` (default `sbc_heldout`).
It works incrementally on whatever `mock_*.pkl` have landed (no hard 48 assert; partial
pkls are skipped). It prints/writes:

- per-mock n_s, A_p, τ₀-amp, dτ₀ pulls; headline summary with the n_s **GATE**
  (`|mean| ≤ 0.3 & std ≤ 1.1`, `analyze_sbc_heldout.py:120-146`); subDLA + LLS α pulls;
  the **loglik-rank** (ideal 0.5, z-resolved path) (`:148-153`).
- τ₀ amp/dτ₀ are recovered by regressing each draw's 13-rung τ₀ ladder
  (`z = 2.2 + 0.2·i`, asserts `n_tau0==13`) in centered `ln(1+z)`
  (`analyze_sbc_heldout.py:30-33, 64-106`).
- a JSON summary + a 3-panel headline figure to
  `/home/mfho/hcd_priya_notes/figures/analysis/05_likelihood/<prefix>_*`.

(The richer self-draw figure set is `scripts/_sbc_prod_summary_analysis.py`, which expects
exactly 48 mocks in `prod_sbc_corrected`.)

### 4b. Self-draw rank aggregation — `scripts/merge_prod_sbc_shards.py`

```bash
PYTHONNOUSERSITE=1 PYTHONPATH=/home/mfho/hcd_priya JAX_PLATFORMS=cpu CUDA_VISIBLE_DEVICES="" \
  /home/mfho/.conda/envs/emu-jax/bin/python3 \
  scripts/merge_prod_sbc_shards.py --shard-dir <OUTDIR>
```

Globs `mock_*.pkl` (per-mock pkls WIN over any `shard_*.pkl` on an index conflict; the mock
index is parsed from the FILENAME) (`merge_prod_sbc_shards.py:59-94`), runs
`aggregate_leg_a`, and prints per-quantity ECDF rank-uniformity PASS/FAIL with the
`gate_valid (L≥99)` flag (`:94-114`). Figure ->
`figures/analysis/06_validation_summary/prod_sbc_pilot.png`.

### 4c. The per-mock pkl record schema

Each `mock_{m:04d}.pkl` is one dict (`closure_legb.py:2056-2060`, `run_legb`), stamped with
`run_cfg` by the runner (`run_prod_sbc_shard.py:104`):

| key | meaning |
|-----|---------|
| `sim` | held-out sim name, or `"leg_a_prior"` for self-draw |
| `truth_vec` | `(P,)` truth in packed order: `[θ9, τ₀(kept z), alpha_lls, alpha_subdla, alpha_dla, (A_hcd/B_hcd/r_subdla/r_dla if hierarchical), (a_SiIII if metals)]` |
| `draws` | `(L, P)` thinned NUTS draws, same column order |
| `names` | column names from `_packed_names_for` (`closure_legb.py:1927`); θ9 = `ns, Ap, herei, heref, alphaq, hub, omegamh2, hireionz, bhfeedback` + `tau0_z{i}` + the 3 α |
| `L` | thinned draw count |
| `ll_true`, `ll_draws` | loglik of the truth + each draw on the same mock (Modrak rank; **z-resolved**, `require_zresolved=True`) |
| `n_div` | divergences in the accepted attempt |
| `kept_global`, `dropped` | which z rows survived the nearest-z map |
| `run_cfg` | `dict(leg_a, cemu_variant, amp_sigma)` — the config-key skip-cache stamp |

## 5. Gotchas

- **Held-out needs `--mem=32g`.** 16g OOMs (the N=5 ensemble forward + dense-mass NUTS on
  the 26-dim posterior peaked at MaxRSS ≈ 16.77 GB on 16g and lost the whole shard before
  the per-mock checkpoint existed) (`batch_sbc_heldout.sh:19`, `run_prod_sbc_shard.py:11-18`,
  `batch_prod_sbc_slfix2.sh:7-8`). The held-out batch uses 32g; the per-mock checkpoint now
  caps the loss to ≤1 mock.

- **Slow hard-posterior NUTS stragglers.** A few mocks have hard posteriors where NUTS
  saturates `max_tree_depth=10` (and the divergence-retry escalates `target_accept` to
  0.95/0.99, each retry a full re-run) — these can hit the 24h wall. Handle with a longer
  `--time` or just re-submit that one array index (§2c); the skip-cache resumes the rest.
  Per-mock warmup luck means the same index may finish fine on a fresh seed-independent
  retry only if you delete its (absent) pkl — but for a TRUE straggler keep the same seed
  and give it more wall.

- **The config-key skip-cache halts on a mismatched OUTDIR.** The pkl is keyed by index
  ONLY (`mock_0007.pkl`), with no leg_a / cemu_variant / amp_sigma in the filename. The
  runner stamps `run_cfg` into each record and, on a skip, **ASSERTS the existing stamp
  matches the requested one — RAISING `config CLASH` on a mismatch**
  (`run_prod_sbc_shard.py:62-97`). So a held-out (or cemu-variant / width-check) run pointed
  at a dir that already holds self-draw pkls will FAIL LOUDLY, not silently mix populations.
  **Fix: give every config its own `OUTDIR`** (the `amp020` / `_heldout` dirs exist for
  exactly this). Pre-stamp (old) pkls are treated as the default
  `leg_a=True/cemu=current/amp=0` config.

- **The `require_zresolved` guard.** The deployed `_legb_model` and the SBC re-scoring
  (`ll_true` / `_loglik_of_draws`) pass `require_zresolved=True`, which **asserts the HCD
  α is z-RESOLVED `(n_z, 3)`** — a `(3,)` z-flat α raises (`data_likelihood.py:839-863`,
  `closure_legb.py:1389, 2045-2051, 2080`). This kills the recurring z-flat-α bug class (a
  z-flat α silently broadcasts and fabricates a spurious z-ramp vs the z-resolved truth;
  see the `feedback-diagnostic-deployment-consistency` memo). If you add a re-scoring path,
  feed `alpha_hcd_z`, not the pivot `alpha_hcd`.

## 6. Reproduce the production n_s certification

The N=48 held-out SBC at the production prior (6 noise realizations × 8 held-out sims),
deployed forward and `C_emu`:

```bash
# 1. Launch (cavestru1, 32g, 24h, default seed 20260614, production prior):
N=48 sbatch --array=0-47 scripts/batch_sbc_heldout.sh
#    OUTDIR defaults to /scratch/cavestru_root/cavestru1/mfho/prod_sbc_heldout

# 2. (resume any walled straggler, e.g. mock 37, with more wall — others skip instantly)
sbatch --array=37 --time=48:00:00 scripts/batch_sbc_heldout.sh

# 3. Analyze (works incrementally; reads the n_s gate + tau0/dtau0 + alpha pulls + loglik-rank):
PYTHONPATH=/home/mfho/hcd_priya /home/mfho/.conda/envs/emu-jax/bin/python3 \
  scripts/analyze_sbc_heldout.py \
  /scratch/cavestru_root/cavestru1/mfho/prod_sbc_heldout sbc_heldout
```

**PASS** iff the n_s pull `|mean| ≤ 0.3` AND pull-std `≤ 1.1` (the gate prints `PASS` /
`FAIL` / `underpowered(N<4)`). Always read the τ₀-amp and dτ₀ pulls in the same summary
(mean flux is the suspected n_s driver). The figure + JSON land in the notes repo at
`figures/analysis/05_likelihood/sbc_heldout_*`.
